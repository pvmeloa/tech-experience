# Tech Experience 2026

Formulário de inscrição nas oficinas do evento Tech Experience 2026 — atividade de Desenvolvimento Web (PHP & integração full stack).

## Arquivos

- `index.html` — formulário de inscrição
- `style.css` — estilo e responsividade
- `script.js` — contador de caracteres e validação no cliente
- `processar.php` — recebe o POST, valida e mostra o resultado

## Como rodar

```bash
cd tech-experience
php -S localhost:8000
```

Abrir `http://localhost:8000/index.html`.
